Famspace unlock - install checklist
====================================

Install (simplest):
  1. uninstall the current Famspace completely (long-press -> uninstall, or
     "adb uninstall com.famspace.app.android") - a half-updated install can
     keep the old proxy code
  2. delete the previously downloaded APK/XAPK from the phone
  3. install Famspace-universal.apk (one file, no XAPK installer, no splits)
     or FamSpace-unlocked.xapk with an XAPK installer
  4. OPEN THE APP and leave it in the foreground for a moment

  The rewrite proxy runs INSIDE the app process, so nothing listens on
  127.0.0.1 until the app is running. Open the app first, then the log URL.

Checking the build and the wallet
---------------------------------
Open this in the phone's browser (while the app is running):

     http://127.0.0.1:8888/__famunlock/log
     http://127.0.0.1:8888/__famunlock/health

The FIRST line of the log page is always a banner:

     FamUnlock proxy build 2026-11-26-wallet2  listening on ports 8888,888

  * banner present  -> this is the current build, the diagnostics below apply
  * no banner       -> an OLD build is still installed (it used port 888 and
                       has no diagnostics). Uninstall it and install the
                       current file.

8888 is the port the app talks to. 888 is the legacy port and only binds on
devices that allow privileged ports, so on a normal phone use 8888.

What the log says about the wallet:

  "rewrote /api/v1/me/profile: [gems, coins, ...]"
      the rewrite fired.  The next line ("app sees ...") shows the JSON the
      app actually receives.
  "no rule matched /api/v1/me/profile"
      the answer arrived but carried no known wallet field - the
      "body ..." line shows what the server actually sent.
  "not json ..." / "body is not a JSON object ..."
      the answer was not plain JSON - the snippet shows what came back.

Every answer that mentions coin/gem/vip/premium is logged with its body, so
the wallet can be traced in any response, not only in the profile.

If it refuses to install, adb prints the exact reason:
  INSTALL_FAILED_INVALID          -> a .so was compressed (wrong file)
  INSTALL_FAILED_UPDATE_INCOMPATIBLE -> the Play version is still installed
  INSTALL_FAILED_MISSING_SPLIT    -> the splits were not installed together
