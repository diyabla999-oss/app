Famspace unlock - install checklist
====================================

Published build (verified by famspace-unlock/verify_build.sh + verify_apk.sh):
  md5 / sha256 of every file are below.

Install (simplest):
  1. uninstall the original Famspace (Play version) - the patched build has a
     different signature, installing over it fails with
     INSTALL_FAILED_UPDATE_INCOMPATIBLE
  2. delete any older copy of the app from the phone
  3. tap Famspace-universal.apk to install it - one file, no XAPK installer,
     no splits, no second app
  4. open Famspace - the proxy starts inside the app, nothing else to do

Install (XAPK instead):
     adb install-multiple -r com.famspace.app.android.apk config.arm64_v8a.apk config.xxhdpi.apk

If it still fails, adb prints the exact reason, e.g.
  INSTALL_FAILED_INVALID          -> a .so was compressed (wrong file)
  INSTALL_FAILED_UPDATE_INCOMPATIBLE -> the original app is still installed
  INSTALL_FAILED_MISSING_SPLIT    -> the splits were not installed together


Wallet check (why the balance may still look wrong)
---------------------------------------------------
The proxy rewrites the server's answers.  After logging in, open this in the
phone's browser:

     http://127.0.0.1:8888/__famunlock/log        (or :8888/__famunlock/log)
     http://127.0.0.1:8888/__famunlock/health

Both ports are served - 8888 is the one the app talks to, 888 is the legacy
port (only bindable on rooted devices).

In the log, look at the line for the profile:

  "rewrote /api/v1/me/profile: [gems, coins, ...]"
      the rewrite DID fire; the next line ("body /api/v1/me/profile: {...}")
      shows the raw server answer, so the exact field names are visible
  "no rule matched /api/v1/me/profile"
      the answer arrived but no known wallet field was in it - the body line
      shows what the server actually sent
  "not json ..." / "body is not a JSON object ..."
      the answer was not plain JSON - the snippet shows what came back

Every answer that mentions coin/gem/vip/premium is logged with its body, so
the wallet can be traced in any response, not only in the profile.
