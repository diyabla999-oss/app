Famspace unlock — downloads

Before you install
1. Uninstall the original Famspace (Play version). The patched build is re-signed with a different key, so an update over the Play install fails with INSTALL_FAILED_UPDATE_INCOMPATIBLE.
2. Delete any previously downloaded copy of the app from the phone — older builds were broken and do not install.
3. Install Famspace-universal.apk (one tap) or the XAPK with an XAPK installer. If you use the XAPK, all splits have to be installed together.
Nothing else to do
The rewrite proxy is compiled into the app and starts with it, so there is no second app to install and no service to keep running. Just install the XAPK and open Famspace.
Simplest: one APK, one tap
Famspace-universal.apk is the whole patched app in a single file — base + native libraries in one package. Copy it to the phone and tap it. No XAPK installer, no split handling, no second app.
Everything is compiled into the app, so there is nothing else to start: open Famspace and it works.
Current state
The app installs, logs in, no longer redirects to the Play Store — and the wallet and Premium are rewritten: the coins and gems show 999 999 999, the VIP level is 99 and the Premium expiry runs to 2038.

The API encrypts every answer into responseData, so the wallet sits inside an encrypted payload — but that encryption was reverse engineered out of the app's Dart code: base64(ciphertext ‖ index byte), where the index byte picks one of sixteen AES-128 keys (the table is in the app's object pool) and the IV is the key itself. The proxy decrypts every answer, rewrites the wallet inside it and encrypts it again, so the app decrypts it exactly as it would the original.
Check the wallet
Open the app first — the proxy runs inside the app process, so nothing listens on 127.0.0.1 until the app is running. Then open http://127.0.0.1:8888/__famunlock/log in the phone's browser.
The first line is always a banner: FamUnlock proxy build 2026-11-27-wallet8  listening on ports 8888,888. If it is missing, an old build is still installed.
Then open the me page of the app and look for this line in the log:
wallet: coins=999999999, gems=999999999, vipLv=99, vipEnd=2147483647
That is the wallet the app is going to show. VERIFY.txt explains what to look for.
